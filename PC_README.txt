RICOH抽選応募準備 PC版
======================

【いちばん簡単な使い方】
1. RICOH_Entry_Assistant.exe をダブルクリックします。
2. 初回だけ、RICOHの注文者情報と同じ氏名・住所等を入力します。
3. ツールがRICOH公式価格と買取ルデヤ価格を取得します。
4. 購入価格に対する粗利益率が5%未満の商品は自動で除外します。
5. 対象商品だけ、ブラウザで入力済み・送信直前のタブになります。
6. 内容を確認して、自分で各タブの「送信」を押します。

このツール自身は送信ボタンを押しません。

【価格判定】
粗利益率 = (買取ルデヤ価格 - RICOH購入価格) ÷ RICOH購入価格 × 100
粗利益率5%以上だけ入力対象です。5%未満と赤字は入力しません。

【価格を取得できない場合】
誤判定を避けるため、その商品のフォームは開かず「要確認」で止めます。
買取ルデヤは、機種名ではなく13桁のJANコードで照合します。

【公式の会員価格が表示価格と違う場合】
通常はRICOH商品ページの公開表示価格を購入価格として使います。
実際の会員価格が違う場合は pc_config.json の
purchase_price_overrides に次のように指定できます。

  "purchase_price_overrides": {
    "RICOH GR IV": 200000
  }

【設定を直す】
PC_RECONFIGURE.bat をダブルクリックしてください。

【個人情報】
氏名・住所等は、このフォルダ内の pc_config.json にだけ保存します。
GitHub、Discord、実行ログには保存しません。

【ログ】
問題が起きた場合は pc_logs フォルダの最新ファイルを確認してください。
個人情報はログへ書きません。
